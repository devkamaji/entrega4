# ONG Transformando Vidas

Projeto de página institucional para uma organização sem fins lucrativos, desenvolvido em HTML e CSS.

## Objetivo

Apresentar a ONG, seus projetos sociais e um formulário de cadastro para voluntários e apoiadores.

## Páginas do projeto

- `index.html` — página inicial com apresentação da ONG
- `projetos.html` — seção com os projetos realizados
- `cadastro.html` — formulário de cadastro de interessados
- `style.css` — estilos gerais do site

## Estrutura

```text
projeto-1/
├── index.html
├── projetos.html
├── cadastro.html
├── style.css
├── README.md
└── img/
```

## Como visualizar

1. Abra a pasta do projeto no VS Code.
2. Clique em qualquer arquivo HTML com o botão direito.
3. Selecione a opção para abrir no navegador.
4. Ou use um servidor local, por exemplo:

```bash
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```
